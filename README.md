# The Common Table

**Pull up a chair. There's always room for one more.**

An original, free, relaxing collection of classic tabletop games, built with React and TypeScript. No ads, accounts, trackers, or paywalls.

The first release introduces a cozy parlor and two locally playable games: American Checkers (two players on one device) and Mahjong Solitaire (a 72-tile Garden layout). More classic games are planned.

See the v0.1 pull request for the initial application, tests and GitHub Pages workflow.
